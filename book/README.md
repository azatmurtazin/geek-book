# geek-book

*The user's guide for the geek-book build engine.*

geek-book reads a directory of Markdown and writes two editions of a book: a
static website and a print-ready PDF. One set of sources, two renderings — the
pages in front of you are built by the engine they describe, so every feature in
this guide is exercised by the build that produced it.

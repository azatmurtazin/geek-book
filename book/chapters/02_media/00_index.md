# Media

*Pictures and diagrams, from the same source to both editions.*

A book carries two kinds of illustration: pictures, which are files the book
keeps or cites, and diagrams, which are written as text and drawn at build time.
Both reach the website and the PDF, and the difference between the editions is
how they are placed, not whether they appear.
